# Daily Masculinity

An Android application for structured Christian daily devotions focused on character, discipline, integrity, spiritual leadership, courage, marriage, and fatherhood.

## Intended experience
- Daily Scripture-centered devotional reading.
- Daily streak and reminder experience.
- Clear, lightweight, fast interface, with content prioritized over elaborate design.
- A structured progression in formation rather than a randomly arranged collection.
