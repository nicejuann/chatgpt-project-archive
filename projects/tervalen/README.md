# Tervalen

An offline-first Android personal growth application, explored with Flutter/Dart and SQLite and incremental device and persistence tests.

## Recovered material
- `Tervalen-Source.zip` and earlier milestone source
- `Tervalen-M2.zip`
- `Tervalen.apk`, `Tervalen-M2.apk`
- Phone guide and validation reports

## Notes
Development milestones included device usability, restart/persistence checks, and a growth-tree experience. Validation results belong to specific builds and devices and should not be generalized.

## Status
Project overview published; implementation files are in the offline backup and not yet committed to this repository.
